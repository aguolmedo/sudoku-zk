Complexity

For an n×n grid (n = 9 here) with k empty cells:

Verify O(n²)
Check each of the 3n rows, columns and boxes, n cells each: 3n² checks. That's linear in the number of cells, so it's polynomial time.
Solve O(nᵏ)
Each empty cell can hold up to n values, so the search tree has up to nk leaves. Backtracking cuts off branches that break a rule early, which is why it actually tries far fewer, but the worst case is still exponential.

The search bound assumes an empty grid. n has to be a perfect square so the boxes fit. Generalized n×n Sudoku is NP-complete: a proposed solution can be checked in polynomial time, and no known algorithm finds a solution in polynomial time in the worst case. Finding one would prove P = NP.

Zero-knowledge proof

The prover convinces you they know a solution to this puzzle without showing you any of it. You play the verifier.

  1. Relabel. The prover picks a fresh random σ that renames the digits 1–9 (say 1→7, 2→3). The grid is still a valid solution.
  2. Commit. The prover publishes hash(value ‖ nonce) for all 81 cells. The values are locked in but hidden; each locked cell shows the start of its hash.
  3. Challenge. You pick one of 28 checks: a row, a column, a box, or the starting numbers.
  4. Open. The prover reveals only those cells, plus σ for the starting numbers. You check every hash and the Sudoku rule.
  5. Repeat. The next round uses a new σ and new nonces.
Completeness
An honest prover passes every challenge.
Soundness (27/28)ᵏ
A wrong grid fails at least one of the 28 checks, so each round catches a cheater with probability at least 1/28. After k rounds, a cheater gets through with probability at most (27/28)k.
Zero knowledge
Each opened row, column or box is a random arrangement of 1–9 because σ is fresh, and you already knew the starting numbers. You could have generated everything you see yourself, so you learn nothing about the solution.

Based on Gradwohl, Naor, Pinkas & Rothblum (2007), Cryptographic and Physical Zero-Knowledge Proof Systems for Solutions of Sudoku Puzzles. Because Sudoku is NP-complete, this gives a zero-knowledge proof for every problem in NP (Goldreich, Micali & Wigderson, 1986).
